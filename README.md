# Yedek Parça Operasyon Kontrol Kulesi

Anadolu Isuzu yedek parça operasyon kontrol paneli tasarımının statik HTML/CSS/JS uyarlaması.

## Dosyalar
- `index.html` — sayfa yapısı
- `style.css` — tüm görsel stiller
- `data.js` — kartlarda/tablolarda/grafiklerde görünen örnek veriler (kolayca değiştirilebilir)
- `app.js` — verileri sayfaya basan ve grafikleri (Chart.js) çizen kod

## Yerelde çalıştırma
Sadece `index.html` dosyasını tarayıcıda açmanız yeterli. Hiçbir kurulum gerekmez.
